À propos

Un pont entre Paris et New York.

π.stream est un système embarqué sur Raspberry Pi 4 qui télécharge automatiquement une vidéo depuis Dropbox et la diffuse en boucle sur un téléviseur — sans aucune intervention manuelle.

01

Dépôt dans Dropbox

Déposez votre fichier vidéo depuis n'importe quel appareil, depuis n'importe où dans le monde.

02

Synchronisation automatique

Un script Python détecte le fichier via l'API Dropbox et le télécharge automatiquement sur le Raspberry Pi.

03

Diffusion en boucle

mpv lance la vidéo en plein écran et la répète indéfiniment, sans aucun écran noir entre les lectures.

04

Contrôle à distance

Tailscale ouvre un tunnel SSH sécurisé pour administrer le système depuis n'importe où dans le monde.

Fonctionnalités

Tout ce dont vous avez besoin.

Conçu pour être simple, robuste dans le temps, et contrôlable à distance sans effort.

Synchronisation Dropbox

Intégration native avec l'API Dropbox pour un transfert de fichiers automatique et fiable.

Lecture en boucle

mpv assure une lecture continue et fluide en 720p via Wayland sur Raspberry Pi OS.

Démarrage automatique

Service systemd configuré pour lancer π.stream dès le démarrage, sans intervention.

Accès SSH distant

Tailscale crée un VPN mesh sécurisé pour un accès depuis n'importe où dans le monde.

Sécurisé

Connexions chiffrées de bout en bout. Aucune donnée personnelle collectée ni transmise.

Raspberry Pi natif

Optimisé pour Raspberry Pi 4, le matériel le plus accessible pour ce type de déploiement.

Stack technique
Raspberry Pi 4 Python 3 Dropbox SDK mpv Player systemd Tailscale Raspberry Pi OS
